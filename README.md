# Verdent Content Lab · Mochi & Lucky 内容工作室

Private repository for reusable original cat stories, comics, HTML animation, scripts and social content / 长期保存与复用原创小猫故事、漫画、HTML 动画、脚本和社媒内容的私有仓库。

**Character first. Joke second. Product third. / 先人物，再笑点，最后产品。**
Documentation: English + Chinese. Finished content: English only / 仓库说明双语，成品全英文。

## Stable Structure · 简单且稳定的结构

```text
verdent-content-lab/
├── README.md / PROJECT_BRIEF.md / CONTENT_MAP.md / HANDOFF.md
├── brand/          Rules, style, product facts, proposed stories / 设定、画风、功能、提案
├── characters/     Profiles, private references, reusable art / 档案、私有参考、共享素材
├── motion/         001–005, their templates, audio, previews, permanent versions / 作品与永久历史
├── comics/         EP.06, EP.07 and special/idea briefs / 正篇及节日选题
├── captions/       English publishing copy / 英文发布文案
├── docs/           Optional browser copies, not source / 浏览器副本，非源码
└── scripts/        Build and archive tools / 构建与归档
```

Do not reorganize by moving/deleting old works. Keep links stable and use this navigation / 不靠搬移删除旧作整理，保持路径与旧版链接稳定。

## Important Distinctions · 不要混淆

**Style approval ≠ film approval ≠ Git sync ≠ publication. More versions ≠ better animation / 画风确认不等于成片确认、同步或发布；版本多不等于动画达标。**

Current factual status lives only in [CONTENT_MAP.md](CONTENT_MAP.md). Every HTML/audio archive stays. Private photos stay outside `docs/`. The supplied logo stays unchanged / 实际状态统一查总表；所有历史保留，真猫照片不进预览目录，官方 Logo 不改原文件。
