# Production Stages · 制作阶段说明

This guide defines the workflow, not a completion percentage. The actual current stage/artifacts live in [CONTENT_MAP.md](CONTENT_MAP.md) / 本说明定义流程，不把阶段数当完成百分比；当前状态以总表为准。

| Stage / 阶段 | Work / 做什么 | Exit gate / 进入下一阶段的条件 |
| --- | --- | --- |
| 1 · Direction & story / 方向与故事 | Confirm identity, style, tone and one episode's storyboards / 确认人设画风、冷幽默与本集分镜 | Creator accepts a clear story and consistent original cats / 创作者接受故事及造型 |
| 2 · Acting proof / 角色动作验证 | Complete-character key drawings, contact/return motion, reaction timing and short scene tests / 完整角色关键帧、接触收回、反应节奏及短段试播 | No detached limbs, holes, obvious face/scale drift; convincing continuous action accepted by creator / 无断肢露洞与明显换脸跳尺度，连续表演获确认 |
| 3 · Full episode & QA / 整集制作验收 | Extend accepted motion through the full story, coordinate English child voices/music, actual browser playback and recording / 铺完整集，协调童声配乐，浏览器实播实录 | Complete film approved at target phone format, sound and muted viewing both work / 目标尺寸、开关声音均验收 |
| 4 · Delivery & reuse / 发布与复用 | Save versions, authorized private Git sync, approved video/caption delivery and actual publication record / 保存历史，授权同步，交付视频文案，真实发布后记进度 | Real post released; approved assets/templates reused deliberately / 真实上线后再标已发布，确认资产再复用 |

Repository setup and reusable rules support all stages; they do not mean the first animation is already accepted. Existing child audio does not mean acting is finished / 仓库和规则是制作基础，不代表首集动画已验收；有童声音轨也不代表表演完成。

More drawings should fill a specific action gap, not expand unrelated poses or episodes while a broken action remains / 新增画稿要补具体动作缺口，不在断爪未修好时堆无关姿势或扩集。
