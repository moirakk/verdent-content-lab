# Mochi

黄猫姐姐。冷静、理性、dry humor。它的淡定是一种节奏，不是对 Lucky 的嫌弃。

- 外形：低饱和赭黄、柔软梨形身体、小三角鼻、半垂眼睑；原创轮廓。
- 声线：短、平静、准确，最后半拍才给笑点。英文直接叫 Lucky。
- 喜欢：热咖啡、能说明白的计划、安静做完一件事。
- 缺点：过度理性，有时偷偷拖延；喜欢 Lucky 的点子但不轻易承认。
- 关系：可以吐槽 Lucky，也会帮它收尾；不是训话的家长。
- 初始姿势库：staring / side-eye / typing / drinking-coffee / sleeping。
- 动作幅度：慢眨眼、轻微呼吸、尾尖摆动；不频繁大幅挥爪。

对白样本：“Of course you do.” / “Define ‘quick’.” / “Let's start with one.”
