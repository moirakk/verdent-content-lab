# Lucky

黑猫弟弟。热情、活泼、容易上头。它的冲动来自真诚好奇，不是无能。

- 外形：柔软温黑轮廓、奶油色眼睛、微微歪头和竖起的耳朵；原创轮廓。
- 声线：先兴奋分享，再意识到细节；英文直接叫 Mochi。
- 喜欢：新点子、新项目、凌晨突然想到的“简单改动”。
- 缺点：低估工作量，把第一步想成整条路线；需要学会停顿。
- 关系：总想把 Mochi 拉进自己的新世界；也能用行动照顾 Mochi。
- 初始姿势库：excited / typing / confused / sleeping / peeking / running。
- 动作幅度：耳朵、尾巴和头部略活跃；不要持续跳动抢走对白。

对白样本：“Mochi, I have an idea.” / “Just one tiny feature.” / “What if we automate this?”
