# Project Brief · 项目总纲

Updated / 更新：2026-10-21（Asia/Shanghai）。This is the current direction, not approval of any finished film / 本文件统一当前方向，不代表任何成片已批准。

## 1. Purpose · 我们到底在做什么

Build a reusable original Mochi & Lucky animated series for Verdent's official social channels, with English stories that are understandable and entertaining before the product appears / 为 Verdent 官媒建立可长期复用的原创小猫动画系列。英文剧情先让人看懂、喜欢角色，再自然理解产品。

**Character first. Joke second. Product third. / 先人物，再笑点，最后产品。**

The deliverable is a short animated story played from HTML and recorded for social media. It is not a presentation, a moving feature list or a collection of cat PNGs / 最终目标是 HTML 播放、可录屏发布的动画短故事，不是动态 PPT、功能清单或猫图片合集。

## 4. Product Storytelling · 产品如何进剧情

Feature-led selection, character-led storytelling. Choose one primary capability, one character desire, one conflict and one payoff / 围绕功能选题，用角色讲故事；每集一个核心能力、一个人物欲望、一个冲突、一个反转。

Hook → character disagreement → visible capability moment → character payoff → readable final hold / 开场事件 → 人物分歧 → 看得懂的功能动作 → 角色反转 → 留停顿。
This is a starting structure, not a mandatory identical formula / 是起步结构，不要求每集套同一模板。

- [Feature inventory](brand/VERDENT_FEATURE_MAP.md): 40 editorial entries, 18 Manager/Desktop + 11 Cloud + 11 VS Code; not an exhaustive product specification or 40 approved episodes / 功能资料库，不是完整规格或已批准排期。
- [Story queue](brand/FEATURE_CONTENT_QUEUE.md): eight review cards; only R01/R02 have existing motion drafts / 八条选题卡，目前只有前两条有动态样片。
- M02 → Motion 003 parallel workers; M01 → Motion 004 goal decomposition / 并行团队与目标拆解分开，不反复复用同一午睡笑点。
- Label illustrative UI versus real recordings and generated outputs; recheck source before claims / 区分示意、真实录屏与实测成果，发布前查来源。
- The Tiny Company world, content ratios and remaining episodes are proposals, not permanent canon or an approved calendar / 小公司世界观、内容配比和后续集数仍为提案，不当作永久设定或已批准日历。
