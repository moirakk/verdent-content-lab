## Core Idea · 核心方向

**Two small cats, one very ambitious company. / 两只小猫，一家野心很大的小公司。**

Build a recurring comedy world around Mochi and Lucky making products, running a tiny business, and trying to have a life. Lucky supplies momentum and surprising ideas; Mochi asks the question everyone else is thinking. Both can be right, tired, or unexpectedly ambitious. This is a proposed recurring setting, not a retroactive change to all existing stories.

建议用两只猫做产品、经营小公司和过日子的连续短剧作为主线。Lucky 推动想法，Mochi 追问现实；两只都可以聪明、犯懒、偶尔上头。小公司世界观是新提案，不反向改写旧故事。

The audience should remember the cats and gradually understand what Verdent helps them do. Product capabilities create story possibilities; each episode still needs a character desire and a payoff.

观众先记住角色，再逐渐理解 Verdent 能帮它们做什么。功能提供故事条件，每集仍要有角色欲望和结尾反转。

## Episode Rhythm · 单集节奏

1. Hook: an understandable claim or situation in the first frame / 首帧抛出能立刻理解的事件。
2. Tension: Mochi or Lucky challenges it / 另一个角色提出质疑。
3. Reveal: a visual change makes the product capability legible / 用可见变化交代产品能力。
4. Payoff: return to the cats for the joke / 回到角色完成反转。
5. Hold and loop: leave reading time; end without a forced sales card / 留时间读完，循环收尾，不强塞销售卡。

Motion 003 is the pilot: founder claim → no employees → Manager's parallel workers → Chief Nap Officer. The aim is a stronger narrative, not a guarantee of IG engagement.

动态 003 为试播：创业宣布 → 员工质疑 → Manager 并行团队 → 首席午睡官。目标是加强剧情，不承诺平台传播效果。

## Reusable Production Kit · 长期复用资产

| Keep stable / 固定资产 | Vary per episode / 每集变化 |
| --- | --- |
| Cat identities, gouache texture, official logo / 角色身份、水粉笔触、官方 Logo | Desire, conflict, scene composition, payoff / 欲望、冲突、构图、反转 |
| Child-voice direction: calm Mochi, eager Lucky / 童声方向：冷静 Mochi、兴奋 Lucky | Exact casting pending review, plus rhythm and acting / 具体音色待审，语速与表演随剧情变化 |
| A small original instrumental palette / 少量原创配乐音色 | Melody, pauses, stings / 旋律、留白、短音效 |
| Timeline, subtitles, audio controls, archive tooling / 时间轴、字幕、声音控制、归档工具 | Dialogue, shot timing, selected product moment / 对白、镜头节奏、产品片段 |

Keep finished content English, documentation bilingual, and every HTML version permanent. Use the supplied logo file without redrawing or stretching it. Sound must support dialogue; captions also make the joke understandable with audio off.

成品英文，说明双语，每版 HTML 永久保留。Logo 使用创作者提供的原文件，不重画、不拉伸。配乐服务对白，关声音也能靠字幕看懂笑点。
